Dev tools

Test fixtures for the t-shirt distribution flow. Not part of the event-day setup.

QR generator → Type a roll number, get a QR whose payload is exactly that text. Verifies itself by decoding the QR it just drew. Test scanner → Scans a QR and calls the real Express API, with a full request/response log of every GET /api/students/:rollNo and POST /api/students/:rollNo/collect. Real phone scanner → The production scanner staff use on event day. Unchanged. Dashboard → Live collection stats.

These pages are served only when the server starts with DEV_TOOLS=1 (npm run dev:tools). A normal npm start does not expose /dev at all.

Collections made from the test scanner are real database writes. Set collectedBy in its Settings so they are easy to spot, and re-import the CSV or restore a backup before the event.
